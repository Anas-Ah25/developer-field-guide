## Limits

Browser exercises are deliberately limited simulations. They are not a complete shell, Git implementation, Docker engine, or Google Cloud emulator. Unsupported commands explain the limit instead of being executed.

The PowerShell companion script was reviewed but not executed on a real Windows host. Native PowerShell command names in the browser exercise were exercised against the simulation. Docker containers and cloud resources were not launched during preparation. Printing was checked through print-media rendering; generated PDF pagination remains browser-dependent.

Local profiles do not provide authentication or automatic synchronization. Clearing browser storage can remove progress; export/import is the backup and transfer mechanism.
